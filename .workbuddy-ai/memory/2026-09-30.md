2. **测试暴露并修掉的 5 个实现 bug**（都不是测试写错）：
   - `filename_parser.dart` `_pureNumber = RegExp(r'^\d{1,4}$')` **没有捕获组**，而调用处读 `group(1)`
     → `[组名][片名][01][1080p]` 这种最常见的动漫命名在扫描时直接抛
     `RangeError: Value not in range: 1`，**整个扫描崩掉**。加捕获组。
   - `filename_parser.dart` `_audioCodecOf` 尾部守卫用 `(?![0-9a-z])`，
     而声道数紧跟在编码后面（`DDP5.1`）→ 最常见的 `DDP5.1` 识别不出来。
     改成 `(?![a-z])`（左边仍卡 `(?<![0-9a-z])`，`EAC3` 里的 `ac3`、`hddvd` 里的 `dd` 不会误命中）。
   - `filename_parser.dart` `_cleanTitle` 留下半个括号：`流浪地球2 (2023)` 会在第一个
     技术标记（年份）处截成 `流浪地球2 (` —— 这正是类文档里举的例子。
     加一条「去掉只有开括号、没有配对闭括号的尾巴」。
   - `filename_parser.dart` `_splitScripts` 把紧贴汉字的数字丢进 latin：
     `流浪地球2` → `latinTitle = "2"`，而它会经 `_pickAlternate` 被当成英文备用
     查询词发给 TMDB。改为「紧贴汉字的数字归 cjk」。
   - `quality_option.dart` `QualityLabels.sortWeight` 原画返回 `-1000`，而 4K 是 `-2160`
     → **数值更小反而排在前面，清晰度菜单第一项成了 4K 而不是原画**。
     改用哨兵常量 `_originalWeight = -100000`。

3. **macOS 沙箱 entitlements 缺 `com.apple.security.network.client`**（Debug/Release 都没有）。
   开了 `app-sandbox` 却没给网络客户端权限 → 应用发不出任何请求：

过程中修掉三个**都会让应用不可用**的问题，全部落在配置而非 Dart 代码里
（所以 `flutter analyze` 一个都查不出来）：

1. **entitlements 缺 `com.apple.security.network.client`**（Debug + Release）。
   沙箱开着却没有网络客户端权限 → 应用发不出任何请求。
   已验证：签名后的 app 里该键存在。
2. **部署目标 10.14 → 10.15**。下限来自 `media_kit_video` → `wakelock_plus` 的 podspec。
   另外 `platform :osx, '10.15'` **只作用于 Runner 目标**，pod 仍按各自 podspec 的版本编译，
   所以 Podfile 的 `post_install` 里逐个 target 覆盖了 `MACOSX_DEPLOYMENT_TARGET` ——
   不覆盖时 `flutter_inappwebview_macos` 以 10.14 编译报
   `protocol 'ASWebAuthenticationPresentationContextProviding' requires
   'presentationAnchor(for:)' to be available in macOS 10.14 and newer`。
3. **media_kit 的 mpv 符号链接**。upstream 的 `create_framework_symlinks.sh` 带 CRLF，
   `sh` 直接 `set: -: invalid option` 退出；Makefile 里那句去 CR 的 `sed` 又被
   工具链的 brokered shim 顶掉 → `.symlinks/mpv` 为空 → `ld: framework 'Mpv' not found`。
   在 Podfile 里用纯 Ruby（`cloudcine_fix_media_kit_symlinks`）补链接，不依赖 sed/make。

改动的文件：
- `macos/Runner/DebugProfile.entitlements`、`macos/Runner/Release.entitlements`
- `macos/Podfile`（platform 版本 + post_install 覆盖 + 符号链接补齐函数）

### 实测发现的 UX 缺陷（**未修**，等定夺）

`media_works` 在遍历阶段**恒为 0**：作品行只在「遍历正常结束后」由阶段二创建
（`scan_service.dart` 阶段二注释即如此设计）。而媒体库页面读的是 `media_works`，
空列表时渲染 `_NeverScannedState`，文案是「媒体库还是空的 / 点『扫描』把网盘里的视频全部找出来」。

→ **扫描进行中（大库可能几十分钟）打开媒体库，会看到"还没扫过"的引导，与事实相反。**
建议：空态里判一下 `scanProgress.isRunning`，改成「正在扫描：已发现 N 个媒体…」。
