## PC 独立播放窗口：切集体验（点击即切）

**问题**：右侧剧集面板点另一集后，画面/声音还停在上一集好几秒（要等「进度落库 → 向主窗口要新直链 → 建中继 → 预热 → open」这条链走完），用户以为没点中。

**改法**（全在 `lib/ui/windows/player_window_app.dart`）：
- 新增 `_switchTarget` / `_switchOpened` / `_queuedEpisode` / `_switchResumeOnAbort`。
- `_beginEpisodeSwitch`：点击那一刻 `setState` 立罩子 + `engine.pause()`（旧流的声音必须先断）。罩子底色用不透明 `AppTheme.cinema`（旧帧已定格，半透明会被读成「卡住」），文案「正在切换到 第N集…」+「正在获取播放地址…」。
- `_clearAwaitingFrame` 加闸：`_switchOpened` 之前忽略「有画面了」信号（暂停本身会再报一次 position，否则罩子一闪就没）。
- `_openStream`：`_switchTarget != null` 时也重置缓存数字（上一集的「已缓存 12 秒」会骗人）；`open()` 前把 `_switchOpened` 翻 true。
- 失败路径 `_abortEpisodeSwitch`：撤罩 + 按 `_switchResumeOnAbort` 决定是否 `play()` 回旧流。
- `_discardEpisodeSwitch`：主窗口推新请求 / `_playRaw` 时作废切集态（否则罩子永远收不掉）。
- `_prepareSource` 预热：切集时 2500ms → **800ms**（旧流已暂停，「多等两秒用户无感」的前提不成立；中继对未落地的块是阻塞等待，剩下的交给播放器首读驱动更准）。
- 连点两集：`_refreshing` 期间不再静默 return，改为记 `_queuedEpisode`，切集/切档/刷链收尾统一 `_drainQueuedEpisode()`（最后一次为准）。
- `_togglePlay` 在切集中直接 return（否则点画面会把旧流 play 回来，罩子下面突然冒声）。
- 面板里「正在切过去的那一行」也点亮（`current: id == currentId || id == _switchTarget?.itemId`）。

**测试**：`test/ui/windows/player_window_app_test.dart` 新增「切集：点了就切，别在上一集卡着」三条（立刻出罩、连点以最后一次为准、取链失败要收罩）。`flutter analyze` 干净，`test/ui/windows/` 307 条全绿。

**未做**：内置播放页 `player_page.dart`（Android/TV + PC 兜底那条路）没动 —— 它走 `PlaybackController.openItem`，同样的「旧流继续播」问题还在，要改得另起一轮。

## macOS 构建失败：部署目标 10.15 → 12.0

**现象**：`flutter run -d macos` 直接 `** BUILD FAILED **`，几十条
`The macOS deployment target 'MACOSX_DEPLOYMENT_TARGET' is set to 10.15, but the range of supported deployment target versions is 12.0 to 27.0.x`
（Runner / FlutterMacOS / 每个 pod 各一条）。本机 **Xcode 27.1**，它不再接受 12.0 以下。

**改了三处（必须同时改）**：
1. `macos/Podfile` → `platform :osx, '12.0'`；
2. `macos/Podfile` 的 `post_install` → 逐个 target 覆盖 `'12.0'`（`platform :osx` 只作用于 Runner，pod 会按自己 podspec 的 10.9/10.14 编译）；
3. `macos/Runner.xcodeproj/project.pbxproj` → 三份 `MACOSX_DEPLOYMENT_TARGET = 12.0;`。
顺带把 `README.md` 与 `.github/release-notes.md` 的系统要求改成「macOS 12.0 (Monterey) 或更高」。

**验证**：`flutter build macos --debug` → `✓ Built …/CloudCine.app`；`macos/Pods/Pods.xcodeproj` 里 12.0 有 93 处、10.15 归零；产物 `Info.plist` 的 `LSMinimumSystemVersion = 12.0`。
（构建收尾有个沙箱告警 `file-write-unlink /Users/tandy/.swiftpm/security`，与工程无关。）
