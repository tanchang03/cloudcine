## 媒体库删除时可选「一并删网盘」（PC + Android）

需求：媒体库里删媒体时，要能选择是否连网盘文件一起删。原来两端都只有「只移除本地索引」，网盘文件永远不动。

### PC（Flutter）
- `domain/services/library_batch_delete.dart`：`LibraryBatchDeletePlan` 新增 `driveFileCount` / `undeletableFileCount` / `alsoDeleteFromDrive` 与 `withDriveDeletion()`；文案按勾选状态二选一 —— `keepFilesWarning`（文件还在）↔ `driveDeleteWarning`（不可撤销）；标题/按钮/`localDataWarning` 也跟着换（勾了之后不许再出现「网盘文件本身不受影响」）。新增 `DriveRemovalSummary`（deleted/failed/fatalError）与 `doneMessage(drive:)`。
- `ui/widgets/library_batch_delete_dialog.dart`：改成 StatefulWidget，加一个**整行可点**的勾选（`_DriveToggle`，默认 false、无记忆）；`show()` 返回 `LibraryBatchDeleteChoice?`（null = 取消）。
- 新增 `ui/providers/library_removal_providers.dart`：`LibraryRemovalController`
  - `tally(keys)` → 可删 / 只读网盘的文件数（弹窗上的「会删 N 个」）；
  - `remove(keys, alsoDeleteFromDrive)`：**先删网盘、再删索引**（fid 只存在 `media_items`）；按 provider 分组、按 `driveMaxFidsPerRequest`(100) 分块；凭证失效/断网中止后续批次并计入 failed；只读网盘跳过不计失败；删完刷新容量。网盘失败**照样**清索引（主操作是移除）。
- `ui/pages/library_page.dart::_removeSelected` 接线（先 tally 再弹窗）。
- 测试：`library_batch_delete_test` +6 例、`library_batch_delete_dialog_test` 重写（含「两段互斥」「默认不勾」）、新增 `library_removal_controller_test` 6 例。`flutter analyze` 干净，29 例全过。

### Android（TV）
- `LibraryActivity.confirmRemoveSelected()`：确认覆盖层给三档（取消 / 只移除索引 / 一并删除网盘文件，不可撤销），第三档只在当前网盘是夸克时出现（电视端百度只读）。
- `doRemoveSelected(alsoDeleteDrive: Boolean)`：先取 `db.itemsForWork` 的夸克 fid（去重）、按 `FIDS_PER_DELETE=100` 分块调 `PanApi.deleteFiles`，再 `db.deleteWorks`；结果文案由 `removalMessage()` 统一（三个数字都说）。
- `LibraryBatchRemoveGuardTest` +2 例（两档且默认只移除索引、先删网盘再删索引）。`:app:testDebugUnitTest --tests LibraryBatchRemoveGuardTest` 通过。

## 19:50 补：电视端也报进度

之后几十秒屏幕静止。改成 `Bg.run` 里每批删完 `runOnUiThread { status.text =

再换「正在清理媒体库…」。分母 `val total = fids.size` 写在循环之前；失败
的批次也推进 `done`。
